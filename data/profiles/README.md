# data/profiles

標準で読み込むデータセット形式（プロファイル）の置き場所です。
公開版では **1 件も同梱していません**。プロファイルが 0 件でも、アプリは
汎用解析（プロファイル未特定）として動きます。

特定のデータセット向けのプロファイルは、ここへ置かずに外部フォルダへ置き、
サーバーの起動時に指定してください。

```bash
DATASET_PROFILE_DIR=/path/to/profiles python3 backend/api.py
```

プロファイル JSON の書き方は
[docs/データセット教材基盤_開発者ガイド.md](../../docs/データセット教材基盤_開発者ガイド.md)
を参照してください。
