# Mochurin WaSeda — マルウェア挙動学習教材（名称は仮）

マルウェアが感染後に何を行うのかを、段階を追って学ぶための教育用教材です。
MWS Cup 2026 に向けて、早稲田大学の Mochurin WaSeda が作成しました。ブラウザ上で動作する静的な頁として構成されています。

利用者は、各段階で観測された挙動を読み、先へ進む前に設問に答え、その後で解説を確認します。
最後に、一連の攻撃の流れ全体を MITRE ATT&CK の手法と対応付けて振り返ります。

## 安全性について

本教材がマルウェアを実行することはありません。

- 表示される挙動は、事前に取得済みの解析環境上の記録、または教材用に作成した架空の例のみです。架空の例には、その旨を明示しています。
- 手元の環境で検体が実行・取得されることは、一切ありません。
- データセットを同梱することも、読み込むこともありません。
- 教材中に記載されている通信先は、すべて文書記述用に予約された範囲（RFC 5737）および example.com です。実在の接続先ではありません。

## 動作条件

Python 3 が利用できる環境であれば、そのまま動作します。導入作業も、追加の部品も必要ありません。

## 起動方法

```bash
cd MWS_MochurinWaSeda
python3 -m http.server 8000 --bind 127.0.0.1
```

起動したら、ブラウザで http://localhost:8000 を開いてください。
終了するときは、実行中の端末で `Ctrl+C` を押します。

### 起動時の注意

**`--bind 127.0.0.1` は必ず付けてください。**
省略すると、すべての通信経路を対象に待ち受ける設定（`0.0.0.0`）になります。
その状態では、学内の無線通信網など、同じ通信網につながっている第三者から、
ファイル一式が閲覧できてしまいます。
この指定を付けることで、通信は手元の環境の中だけで完結します。

**`index.html` を直接開かないでください。**
本教材は ES Modules と `fetch()` を用いているため、`file://` 形式で開くと
ブラウザ側で読み込みが遮断されます。
このとき警告は表示されず、白い画面が出るだけで原因が分かりにくいため、
必ず上記の手順で起動してください。

## 教材の構成

各課は `data/lessons/` に置かれた JSON ファイル一つに対応します。
書式については `lesson-01.json` が実例を兼ねています。

一つの課は、複数の段階（surface → launch → recon → persistence → exfiltration）から成り、
各段階が次の二つを持ちます。

- **観測された事象** — 挙動の記録に、対応する ATT&CK の手法を対応付けたもの
- **設問** — 解説を読む前に、利用者自身に考えさせるための問い

そして課の末尾に、攻撃全体の流れをまとめた振り返りが入ります。

課を追加するには、新しい JSON ファイルを `data/lessons/` に置き、
`data/lessons/index.json` に登録します。

## 補足：実在の検体の挙動を用いる場合（任意）

本教材は、収録済みの架空の例だけで完結して動作します。以下は必須の手順ではありません。

実在の検体の挙動をもとに課を作成する場合は、手元では一切実行せず、
外部の解析環境にハッシュ値で問い合わせ、その結果を JSON に変換してください。

- 問い合わせ先には VirusTotal の無償公開 API を利用できます（ハッシュ値による検索。毎分 4 件、1 日 500 件まで）。利用には、各自で取得した API 鍵が必要です。
- 鍵は手元の環境変数などにのみ設定し、バージョン管理には決して含めないでください。詳細は `js/integrations.js` を参照してください。
- データセットの検体を、外部へ送信してはいけません（再配布条件による）。ハッシュ値による問い合わせのみを行ってください。

## ファイル構成

```
index.html          土台となる HTML
styles/design.css   見た目の定義
js/                 本体（画面遷移、表示設定、読み込み、一覧、進行、設問、振り返り、外部連携）
data/lessons/       各課の JSON と、その一覧
docs/               設計上の取り決め、初期構想図
```
